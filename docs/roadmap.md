# Roadmap

1. Preparación: scaffold, configuración, API health y CI.
2. Ingesta: lectura de SRT/VTT, manifest, metadatos y normalización que preserve tiempos.
3. Indexación: chunking, embeddings Ollama y upsert idempotente en Qdrant.
4. RAG: recuperación filtrada, respuestas con evidencia y citas.
5. Evaluación: dataset, MLflow, latencia y regresiones.
6. Agente MCP: solo después de validar el RAG base.
