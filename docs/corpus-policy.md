# Política de corpus

- No versionar subtítulos descargados, manifest con URLs privadas, bases Qdrant ni trazas.
- Mantener URL de origen, fecha de emisión, programa, idioma, formato y rangos temporales como metadatos.
- Respetar condiciones de uso y límites de petición de RTVE.
- Usar fixtures pequeños y preferentemente sintéticos para las pruebas.
